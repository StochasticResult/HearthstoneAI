# 验证记录 · 2026-11-01

本次记录针对独立应用 0.1，不将早先原型的操作结果算作新应用的实战验收。

## 通过

- 42 项 unittest 用例通过；另有一次性子进程的守护超时、主动终止清理、FPS 修改与恢复检查。
- API 适配使用模拟响应验证：一次只能返回一个动作；错误动作、多个动作、不完整响应、缺失使用量、超额预算均停止；网络调用没有自动重试。
- 新状态与旧建议不匹配时，在发送输入前停止。
- 账号字段、对手隐藏手牌和任意未知嵌套字段不会进入 API 观察对象。
- 同时运行第二个会话被文件锁拒绝；父进程不符时资源守护回收其子进程。
- 三份既有真实练习日志可被新解析器读取，生成公开局面。相关快照的公开 JSON 大小分别约 5.7 KB、6.5 KB、2.2 KB；未上传原始日志。
- 原生应用编译和本机签名检查通过；应用窗口布局已检查；安装后的「离线自检」按钮运行成功。

本次测试套件在独立资源守护下执行：一轮采样峰值约 38 MiB、27% CPU，耗时约 1.6 秒。编译约 2.7 秒，采样峰值约 55 MiB。由于采样间隔较长，这些短任务的瞬时峰值可能未被捕获。应用空闲时一次采样约 90 MiB RSS、0% CPU；此数值不包括炉石、API 决策或后台对局进程。

## 未通过验收／未执行

- 尚未提供实际 API 配置；未发送真实模型请求、未产生模型调用费用。
- 没有在本次新应用中启动炉石、执行实际出牌或完成对局。
- 自动启动、实际身份读数、完整对局、实测 API 延迟／费用、连续运行、窗口适配和排名均未验收。
