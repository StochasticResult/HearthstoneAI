## 具体发现

- 两者都算对了先用受加费的浮空课程，再牺牲自己的法术加费随从，使亵渎降费的多步斩杀；也处理了双加费光环带来的精确 16 点血甲斩杀。
- 两者各有一次复生计算解释错误：漏看复生嘲讽，或漏算第二次回血。首动作仍在正确线路上，因此记部分分，不能直接宣称它们在实际多步执行中一定会漏斩杀。
- Terra 第二遍在硬币题中先下高费随从是可行首步，但理由里的后续“硬币→亵渎”缺少先清除加费光环，按所述顺序法力不够。
- 两者都连续选错吸血目标：我方 4 血，对面 8/8 和 1/1。凝视打 1/1 仍吸血 5 点，9 血能承受剩余 8 攻；打 8/8 留下两只随从、共 9 攻，会死。Sol 一次理由发现了正确目标却没有修改最终动作，另一次错误地把吸血量限制为目标剩余生命。
- 不完全信息题中，两者会根据已用掉的两张月井/暗言术：毁改变加攻策略，也知道生成牌、候选卡组和可能解牌不能等同于已知手牌。现有短理由没有充分展示所有牌型归因过程。
- 随机求生题两者都选择约 94.15% 的获胜机会，并未谎称必胜；Sol 给出了正确概率公式，Terra 用定性表达。

## 方法与限制

这些局面基于实际卡牌文本和当前环境构造，**不是伪称的职业比赛录像**。四条确定斩杀线路由一个只覆盖所用规则的小型独立计算器核对，见 `tactical-witnesses.json`；它不是完整炉石模拟器。原始题目、请求摘要、回复、评分和模型映射均在本目录。

初始评分说明建议用普通随从清复生，但加血后的风怒随从若能活下来，用其中一次攻击清复生也能斩杀。这种正确替代线路已给满分，并在盲审记录中说明；没有强制模型照抄参考线路。

策略分包含人工判断，3 分的总差距很小；没有多局胜率、完整回合模拟或统计显著性。复杂题的 Sol 时延明显更高，需要在真实回合时限内检验。共同的吸血/复生/加费规则错误已用于设计新数值与新圣盾条件的后续测试，修正后的结果应与本轮原始成绩分开看。
